# Subscribe & Save Upgrade for the Shopify Cart

A "Subscribe & save" toggle under each one-time item in the cart drawer: one tap switches the line to a subscription, with a frequency picker and the savings per delivery. It reads the discount and frequencies from your products' selling plans (Shopify Subscriptions or any subscription app that uses them). No extra app.

Built with Claude Code on camera for the BS&Co YouTube channel. Install steps, settings and customization prompts go here once the build is done.
